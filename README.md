# 🏵️ Maio Laranja: Proteja Crianças e Adolescentes

Página informativa sobre a campanha **Maio Laranja**, de enfrentamento ao abuso e à exploração sexual de crianças e adolescentes.

O conteúdo se adapta a quem acessa: a pessoa informa nome e idade e recebe uma saudação e informações com a linguagem adequada para a sua faixa etária, além dos canais oficiais de denúncia e apoio.

## ✨ Destaques

- **Acesso personalizado** por nome e idade, com validação do formulário
- **Fundo animado** com flores desenhadas em `<canvas>` (sem imagens externas)
- **Contatos de ajuda e denúncia** em destaque
- Layout **responsivo**, pensado para celular
- **Arquivo único** (`index.html`): HTML, CSS e JavaScript puros, sem dependências
